# Local AI with Ollama

Run AI models locally on your machine.

## Why I Saved This

Running AI locally means no internet required, no data leaving your machine, and complete privacy. Perfect for sensitive projects.

## Key Findings

- Supports Llama, Mistral, Phi, and more
- One command install: `ollama pull llama3.2`
- REST API compatible with OpenAI
- Works on Mac, Linux, Windows
- GPU acceleration available

## Personal Notes

Great for experimenting with AI without API costs. The quality has improved dramatically in 2026.
